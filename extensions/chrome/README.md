# LingCast Chrome 采集插件

默认服务器从私有`.env`的`LINGCAST_PUBLIC_ORIGIN`读取：配置后执行`python3 extensions/package_chrome.py`，也可用`--env-file <本地文件>`。源码不含真实服务器地址，不提交.env或生成的ZIP。

插件服务器字段默认填好，但可编辑；修改后保存在Chrome本地，重新打开仍保留。更换服务器会清除旧服务器的采集密钥，避免错发；修改仅在下次点击开始时生效，不在后台悄悄切换正在采集的连接。点击开始时只申请所填服务器主机的可选权限；manifest声明HTTP/HTTPS可选范围以支持用户改地址，不自动获得所有网站的访问权限。

从管理员后台为目标数字人生成新采集密钥，复制到插件一次。没有共享默认口令，密钥不写源码或下载包。重新生成/撤销后旧密钥失效。默认数字人ID3；采集只读手动授权的直播页，默认不自动欢迎、回复或感谢。不发送平台评论，不读取Cookie或评论输入框。
