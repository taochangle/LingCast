# 当前状态与后续验证

2026-11-02按仓库实现整理。本页记录能力与尚需持续验证的边界，不是部署指令或对线上即时状态的保证。

## 已实现

- Qwen SSE按完整短句入队，CosyVoice3音频块与MuseTalk 1.5帧配对，经常驻FFmpeg/SRS播放。
- 手动原文口播、Chrome DOM采集、感谢/评论/欢迎独立队列及自主主持。
- 24条固定主持稿，ID3可追加3条换装提示；首段就绪恢复，不必全库等待。
- 点播三类各30条，按场次随机轮换；公开项目部分文件速读与讲稿预览。
- ID3三套准备造型、分阶段换装、按造型隔离媒体缓存。
- 随机可撤销采集密钥、服务端哈希存储、输入输出过滤及管理员会话。

## 持续验证边界

- 平台DOM变化、虚拟列表和后台节流对采集的影响；感谢不得冒充支付凭证。
- 多任务GPU竞争、排队、首帧、浏览器缓冲和平台延迟分别测量。
- 新素材的身份/口型匹配、完整解码、同步与人工观感；技术检查不能代替人工审核。
- 缓存容量淘汰、音色/模型指纹变化、服务重建后的重新准备与回退。
- 当前Worker重建有短暂重连；没有无缝不停播热更保证。
