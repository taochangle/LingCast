# Windows 安装版：语音与口型服务接口

这是安装版开发中的接口约定，不代表图形设置、云端部署或 Windows 完整直播已验收。现有链路是 Worker 调用口型服务；口型服务再调用语音服务。两个服务可以分别在本机或其他机器，但它们使用 LingCast 流式协议，不能将任意厂商的地址直接替换进来。

## 地址和认证

| 配置 | 使用位置 | 默认或作用 |
| --- | --- | --- |
| `MUSETALK_RESIDENT_URL` | 直播 Worker | 口型 API 地址，默认 `http://127.0.0.1:59496` |
| `MUSETALK_API_TOKEN` | Worker、口型服务 | 口型服务专用 Bearer 令牌；未设置时沿用原有 `RESIDENT_API_TOKEN` |
| `COSYVOICE_URL` | 口型服务 | 语音 API 地址，默认 `http://127.0.0.1:59495` |
| `COSYVOICE_API_TOKEN` | 口型服务、语音服务 | 语音服务专用 Bearer 令牌；两端一致；不配置时维持本机原有行为 |
| `COSYVOICE_CACHE_ID` | 口型服务 | 远程语音版本和音色的稳定标识；不设置时远程语音生成的结果不启用复用缓存 |
| `COSYVOICE_REMOTE` | 口型服务 | 语音地址是本机隧道、实际转发至远端时设为 `1` |

地址中的 `127.0.0.1` 始终指发起请求的那台机器。口型服务在云端时，语音地址必须从该云端机器能访问；它不指安装电脑。更换远程模型或音色时必须更新 `COSYVOICE_CACHE_ID`，否则不能识别服务内部的改变。通过本机隧道访问远端语音时，需设置 `COSYVOICE_REMOTE=1`，才能正确应用远程缓存策略。

令牌放在服务各自的私有环境配置中，不放安装包、源码或日志。默认模型服务仍只监听本机；跨机器使用应经有认证的 HTTPS 反向代理或受保护的隧道，并正确限制可访问范围。连接检查须经过相同的认证代理。当前还没有图形设置页面或自动部署云端服务。

## 现有接口

- 语音服务：`GET /readyz` 查询状态；`POST /speech` 接收 `{"text":"..."}`，以 NDJSON 逐行返回 base64 编码的 float32 PCM 块及采样率，最后返回 `done`。启用语音令牌后 `/speech` 要求 `Authorization: Bearer <令牌>`。
- 口型服务：`GET /readyz` 返回就绪状态和已准备的人物映射；`POST /render` 接收 `avatar_id`、`text` 和 `base_key`，要求口型 Bearer 令牌，并以 NDJSON 流返回成对音频和 JPEG 帧。人物与底片不匹配时拒绝处理。

客户端会发送口型令牌给就绪检查与渲染请求；语音令牌由口型服务调用语音服务时发送。服务间流式请求不自动跟随重定向。实际服务状态以 `/readyz` 和完整数据流为准，HTTP 连接成功不等于模型已准备好或直播可用。
