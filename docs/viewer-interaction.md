# 点播小节目

用户已放弃连续会话，不采集用户 ID、不按昵称保存个人记忆。已撤掉本轮个人主页 ID 提取、协议字段和 Redis 对话记忆实现；原有聊天记录逻辑保持原样。

适用于 Chrome 采集的评论，沿用插件「自动回复聊天」开关，不增加开关、权限或插件版本。以下短请求去掉首尾标点后精确匹配：

| 类型 | 示例 |
| --- | --- |
| 笑话 | 讲个笑话、讲一个笑话、来个笑话、笑话 |
| 夸夸 | 夸夸我、夸我一下、夸夸 |
| 晚安 | 晚安、说晚安、来个晚安、说句晚安 |

扩充版每类30条、共90条短稿，按数字人/采集revision/类别共用Redis随机轮换袋；一轮选完才重新洗牌，轮次交界不连续重复。两个API服务原子取稿，服务重启保留进度；闲置24小时后轮换状态过期。换场或更新话术库会开始新轮。取稿后即视为使用，队列满等情况可能跳过该条，不保证每条都实际播放。Redis不可用时跳过本次点播，不降级随机重复。

点播不调用 Qwen 或知识检索，直接以 narration 进入原评论队列。仍然需要 CosyVoice/MuseTalk 合成，未预先生成媒体；重复原文可沿用现有媒体缓存。

优先级继续为：手动口播 → 礼物感谢 → 点赞感谢 → 评论回复/点播 → 欢迎 → 主持。已有两秒限频、消息去重、队列容量、输入输出防注入与房间 revision 检查继续生效；不硬打断当前口播。长句或自由发挥要求走原 Qwen 回复链路。

验证：`node --test extensions/chrome/tests/*.test.mjs` 与后端 `go test ./...`。发布仅更新 api-admin、api-live。无需更新插件、前端、Worker或重启模型。

扩充版验证：`programme_test.go` 检查每类30条、文案无重复、长度和安全规则；`REDIS_TEST_ADDR` 启用 `TestRotationIntegration`，验证整轮不重复、轮次边界、并发取稿和状态过期设置。
