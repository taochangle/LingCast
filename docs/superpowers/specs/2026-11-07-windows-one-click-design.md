# LingCast Windows 一键安装方案

## 目标

面向没有开发经验的用户，在满足显卡和驱动要求的空白 Windows 电脑上，通过双击安装程序完成安装，并通过桌面快捷方式启动直播系统。安装包附带程序、模型、运行环境和必要服务，安装时不要求用户手动安装 Python、Git、Docker、FFmpeg 或执行命令。用户自行填写直播所需的账号、API 凭据与推流配置；安装包不包含真实凭据或私有运行数据。

## 路线和范围

- 采用用户选择的 Windows 原生方案。WSL2/Docker 方案可复用部分 Linux 环境，但要求额外系统组件，当前不作为交付前提。
- 安装程序检查 Windows 版本、磁盘空间、显卡和驱动；条件不满足时用中文说明具体原因和处理方式。显卡驱动由系统或用户安装，不视为复制文件即可完成。
- 安装包携带匹配版本的模型、运行库、服务和经过授权可分发的默认素材。以可校验的资源清单组织；如体积限制需要多个文件，安装程序与资源包仍须支持离线安装。
- 首次运行初始化本机数据和独立密钥，启动本机服务并显示进度、错误和恢复操作；启动完成后打开管理界面。默认仅监听本机，外部推流由用户主动配置。
- 语音合成和口型生成均提供可配置的 API 服务地址，默认使用本机服务；用户可分别切换到兼容协议的云端服务，并分别填写认证信息。配置界面用中文提供连接检查和明确的错误提示，凭据只保存在本机私有配置中，不写入安装包、源码或日志。
- 沿用现有音频分块和音画帧流式协议，服务端点和部署位置不应改变播放顺序与身份匹配约束。当前口型服务负责调用语音服务：分机部署时，语音地址必须从口型服务所在机器可访问，不能把安装电脑的 `localhost` 当作云端机器的本机地址。
- 首版对接遵循 LingCast API 协议的服务，不假定任意第三方 TTS 或口型 API 的鉴权和数据格式兼容。远程连接应使用受保护的传输和认证；本机默认不对公网暴露服务。实际云端部署和远程连通性需单独验收。
- 提供开始菜单和桌面快捷方式、正常退出以及卸载。升级和卸载必须保留用户数据，除非用户明确选择删除。
- 保持现有直播业务行为及人物与预处理数据的对应关系；不能用其他人物的 profile 兜底。现有 Linux 生产部署、凭据和数据不变。

## 技术工作与风险

现有系统包含容器内的数据库、队列、对象存储、媒体服务和 Go API，以及宿主机 Python 模型和 Worker。须先逐项确认原生 Windows 可分发实现，不能假设 Linux 容器或 systemd 存在。直播 Worker 的 FFmpeg 音频管道使用 `/dev/fd` 和 `pass_fds`，需要设计并验证 Windows 的等效实现。CosyVoice 与 MuseTalk 需使用可在 RTX 5070 上工作的版本组合，并验证模型权重、依赖及许可；不能只凭 CUDA 矩阵计算认定模型可用。

安装目录中的 Python 环境、可执行程序和模型路径必须在移动到另一台机器后仍可用；构建机现有工具和路径不是目标机前提。具体安装器、原生服务组合和模型依赖版本由实现阶段根据实际兼容性选定，不预先假定它们已经可用。

## 验收

1. 在目标 GPU 上分别测试 CosyVoice、MuseTalk 的加载、推理、耗时与显存峰值，再测试同时运行和连续直播链路；明确测试机器的系统版本和已有负载。
2. 在没有项目开发工具、模型和相关服务的干净 Windows 环境，以交付文件离线安装；验证空间不足、驱动不满足、端口冲突及异常中断时的可理解提示和恢复。
3. 通过桌面快捷方式启动，验证后台、待机、手动口播、音画输出与停止；正常退出后重新启动。按授权素材和用户配置验证实际直播功能。
4. 验证升级、卸载及用户数据保留，并检查安装包不包含真实凭据、私有配置或运行数据。Windows 10 和 Windows 11 分别实测，不能以其中一个替代另一个。
