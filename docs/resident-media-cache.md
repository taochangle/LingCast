# 常驻口播媒体缓存

相同台词（仅去掉首尾空白）复用 IndexTTS 的 WAV；相同音频内容、人物基础视频及 LatentSync 模型配置复用 MP4。自然切段先复用整段配音，再按原停顿切段，每一段独立查询视频缓存。播放任务编号和发送时间每次重新生成，不复用历史播放状态。

缓存保存在 RustFS `cache/resident/v1/`，服务重启后仍可复用。JSON 索引在模型成功且输出对象存在、非空后写入；不存在、损坏或媒体被删除时重新生成，权限和网络错误会报错。播放使用新建本地临时文件，删除本地文件不影响缓存。日志 `[MEDIA_CACHE] tts/video hit/miss` 和成品 metrics 的 `cache_hit` 可用于核对。

模型 `/readyz` 返回配置指纹：服务源码、检查点/配置/上游源码文件的路径、大小与修改时间、音色文件 SHA256，以及默认口型步数。更新模型、音色或环境参数后须重启常驻服务。人物素材通过 S3 ETag/大小/版本识别。当前参数语言 ZH、语速 1.0、seed 1247、guidance 1.5 固定于服务源码；源码变化会使缓存失效。

同一宿主机、同一对象存储的相同任务用文件锁串行，减少重复计算。多宿主机并发仍可能各自生成一次，索引只指向完整的不可变输出。当前缓存无自动过期或清理，长期运行需要按容量配置对象存储生命周期；不要把短期签名下载地址当作缓存内容。

验证：`cd worker && uv run python -m unittest discover -s tests -v`。测试覆盖重复命中、台词/音色/步数/人物变化失效、缺失媒体恢复和失败不入缓存。
