# 当前功能与边界

本页按2026-11-02代码核对；实际模型、素材、开关和运行状态须在部署环境确认。

## 数字人与素材

创建数字人只建立身份与默认场景，不自动生成可播视频；至少有场景与视频才满足素材就绪。场景下可上传或生成素材。当前GPU直播还要求独立准备对应MuseTalk profile，界面素材就绪不等于口型模型已准备。

## Live Studio

开关数字人直播、原文口播、队列与聊天状态、悬浮监看、外部推流配置；可读取公开GitHub仓库的部分文件，显示固定提交及依据，生成最多220字讲稿，经预览编辑后提交。速读最多选7份文件，单文件内容可能截断，不是完整审计，也不执行仓库代码。

## 主持、点播和换装

- [自主主持](../autonomous-host.md)：自定义1～12段、每段5～70字；固定话术库24条，ID3换装启用后追加3条提醒。首条普通稿就绪即播放，其余后台准备。
- [点播](../viewer-interaction.md)：笑话、夸夸、晚安各30条，精确短请求直接选稿；按场次轮换，不为第三方观众建立按昵称识别的个人连续记忆。
- [换装](../wardrobe.md)：当前口播结束后，旧衣告别 → 静音离场/空镜/新衣入场 → 新idle与renderer → 回场语 → 继续主持。只接受准备好的造型，不支持临时随意指定图片。

## Chrome互动与优先级

用户主动开始只读DOM采集；支持新增评论、进场、点赞、礼物提示，跳过首屏历史，不向平台评论框发送。页面改版、虚拟列表或后台节流可能漏读；只处理页面确实展示的信息。

取下一任务按手动口播 → 礼物感谢 → 点赞感谢 → 评论回复/点播 → 欢迎 → 主持。欢迎/回复各2秒触发限频，不保证2秒开口；点赞合并15秒、礼物2秒限频，有界队列可能跳过。当前短段不硬中断。见[采集](../chrome-collector.md)和[感谢](../thanks-priority.md)。

## 缓存与知识

完整PCM/JPEG事件按人物、文字、底片、模型及参考声音指纹缓存，最多保留256项；不完整输出不复用。缓存位于模型实例磁盘，Worker内存准备状态可重建；容量淘汰、指纹变化仍会重新生成。

知识库采用zvec全文索引与Jieba检索，结合人物设定和房间近期聊天上下文；持久化记录和有限上下文不等于无限长期记忆，也不意味着按第三方用户准确识别连续会话。

## 安全与发布

管理员会话保护管理操作，采集端使用每数字人独立随机Bearer，Redis只存哈希；当前不设自动过期，重新生成/撤销使旧值失效。防注入与内容过滤不保证每个输出安全，原文口播需操作者确认。生产只开放必要网关，不新增模型公网端口。

代码中保留的其他离线引擎和多硬件路径见[历史文档](../history/legacy-readme-zh.md)，不作为当前直播主链路。
